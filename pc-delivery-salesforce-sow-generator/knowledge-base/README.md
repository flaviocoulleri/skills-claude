# Base de conocimiento

Carpeta para documentos que mejoran los SOW generados: templates actualizados, ejemplos de historias de usuario aprobadas, SOWs de referencia de proyectos anteriores, estándares de documentación y mejores prácticas del equipo.

La skill lista y lee el contenido relevante de esta carpeta al inicio de cada ejecución, y lo trata como fuente de estilo y criterio con prioridad sobre sus defaults.

Convención de nombres sugerida: `[tipo]-[tema]-[fecha].md|pdf|docx`, p.ej. `ejemplo-historias-service-cloud-2026-07.md`.

## Contenido actual

- `ejemplo-sow-guillermo-morales-crm.md` — SOW real aprobado (concesionario multimarca, Chile). Referencia principal de estilo de redacción; su sección 5 "Integraciones con Sistemas Externos" es el patrón obligatorio para documentar integraciones (alcance taxativo por entidad, una historia por interfaz con Narrativa/Criterios/Consideraciones).
- `ejemplo-sow-montironi-concesionarios.md` — SOW real aprobado (Montironi, grupo de concesionarios automotrices, Argentina). Referencia OBLIGATORIA para proyectos de concesionarios / industria automotriz: modelo de roles, perfiles y visibilidad por marca/concesionario, gestión de Leads multicanal, objeto custom Vehículo, Boletos y Pruebas de Manejo, integración con DMS, Service Cloud con Omni-Channel y Agentforce. Usar sus épicas e historias como banco de referencia al redactar historias de dominio automotor.
